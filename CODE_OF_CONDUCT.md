# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/) como código de conducta para todos los espacios del proyecto: repositorio, issues, pull requests y canales de chat.

En resumen: trato respetuoso, crítica al código y no a las personas, cero acoso.

Para reportar una conducta inaceptable, escribe a **carlosvisbal66@gmail.com**. Los reportes se tratan con confidencialidad.
